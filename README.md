# 耶拿离线星空

雨夜也要留一片星空。离线播放器配置与活动资料摘录。

活动室那台旧电脑上用的小播放器，负责把画面、字幕和音轨串起来。断网也能放，收工时拔掉网线就不用再惦记它。

这一份同步现场配置、当期值班本和维护便笺。播放器本体和音画素材留在活动室硬盘，拷贝配置时请另带素材目录。

## 文件

- `scene.json`：最近一次导出的场景配置副本。
- `records.md`：白板、器材借用和当期值班记录的誊本，换期时重新誊写。
- `NOTES.md`：还没处理完的维护事项和收件摘录。

## 配置

`build` 是导出时分配的配置编号；`version` 是适用的播放器版本，`schema` 是配置格式版本。换格式时要重新导出。

`resource` 对应硬盘上的素材包，`layout` 对应投影布局。推进方式 `manual` 使用空格键，`auto` 跟随素材内的时间表。每次载入后在状态栏确认素材和布局，再开音箱。

导出件分别拷到 U 盘，素材和配置放在一起，现场只带当天要用的一套。这里的副本供继续试机，不跟随某一台机器的运行状态。
